## OpenMultiConverter 0.1.0 — first release (audio)

Offline Android audio converter, lossless whenever possible. No network permission, no telemetry.

**Highlights**
- Inputs: FLAC, WAV, ALAC, AIFF, WavPack, APE, TTA, DSD, MP3, AAC/M4A, OGG Vorbis, Opus, WMA, AMR, AC-3, MP2, MKA, plus the audio track of video files.
- Outputs: FLAC, WAV, ALAC, AIFF, WavPack (lossless) · MP3, AAC, OGG Vorbis, Opus, WMA, AC-3, MP2, AMR-NB (lossy) · "Original" stream copy.
- Smart conversion: stream copy for the same codec, bit-exact lossless-to-lossless, clear warnings whenever information would be lost.
- Batch / folder conversion, progress notification with cancel, tags and cover art preserved when the container allows.
- Advanced settings: sample rate, channels, bit depth, bitrate, FLAC compression level.

**Install:** download `OpenMultiConverter-v0.1.0.apk` (universal: arm64-v8a, armeabi-v7a, x86_64; Android 8.0+) and verify it with the `.sha256` file.
